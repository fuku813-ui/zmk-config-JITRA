1箱の中身・別途用意するもの

JITRA本体は組み立て済みでお届けします。出荷前にキー入力・トラックボール・エンコーダー・左右間の無線通信は確認済みです。ただし、以下のものは同梱されていません。ご自身でご用意ください。

単4電池2本(左右それぞれ1本ずつ)
キースイッチChoc V2 ロープロファイル対応品 65個
キーキャップChoc V2対応、1U×53 / 1.25U×6 / 1.5U×1 / 1.75U×2 / 2.25U×1 / ISO Enter×1
トラックボール球25mm 1個
USBケーブルType-C(主に充電ではなくファームウェア更新時に使用)
注意: リチウムポリマー電池は使用していません。単4電池(アルカリ/充電式いずれも可)を使用してください。種類の異なる電池や新旧の電池を混ぜて使用しないでください。

2組み立て

  • キースイッチを取り付ける
    本体はホットスワップソケット対応です。スイッチの向き(ピンの向き)を確認し、ソケットにまっすぐ押し込んでください。斜めに挿すとピンが曲がる原因になります。
    (ここにホットスワップソケットの写真を挿入)
  • キーキャップを取り付ける
    表の一覧を参考に、サイズの異なるキー(Enter・Shiftなど)の位置を間違えないよう取り付けてください。
  • トラックボール球を入れる
    右手側(トラックボール搭載側)のソケットに25mm球を乗せてください。落下防止のため、使用中以外は本体を立てたり逆さにしたりしないことをおすすめします。
    (ここにトラックボールソケットの写真を挿入)
  • 電池を入れる
    左右それぞれの電池ボックスに単4電池を1本ずつ、極性(+/-)を確認して入れてください。

3電源の入れ方とペアリング

  • 左右両方の電源を入れます。
  • 右手側(トラックボール搭載側)がPC/スマートフォンとBluetooth接続される「親機」です。PC側のBluetooth設定から「JITRA」のような名前のデバイスを探して接続してください。
  • 左右間は自動的に無線接続されます。しばらく経っても左手側の入力が反映されない場合は、一度両方の電源を入れ直してください。
複数台のPCを切り替えて使いたい場合は、本書「レイヤー」の章にあるBluetoothプロファイル切り替えをご利用ください(最大5台まで登録できます)。

4動作チェック

ペアリングが済んだら、専用の動作チェックページですべてのキー・トラックボール・エンコーダーが反応するか確認できます。押したキーが画面上で緑に変わるので、反応しないキーがひと目でわかります。

押した位置で判定するため、OSのキーボード配列設定(JIS/US)に関係なく確認できます。

動作チェックページを開く

ブラウザはパソコンのChrome・Edge・Safariなどをお使いください。スマートフォンでは確認できません。

5キーマップの基本

基本的な配列は、Macの日本語(JIS)キーボードにほぼそのまま準拠しています。「かな」「英数」キーも同じ位置にあります。Macにお使いの場合は特別な設定をしなくても違和感なく入力できるはずです。

キーボード本体の下段(親指で押す部分)だけは、方向キーを省略した分レイアウトが異なります。

段内容
数字の段ESC ・ 1〜0 ・ - ・ ^ ・ ¥ ・ 削除(Backspace)
上段Tab ・ QWERTYUIOP ・ @ ・ [ ・ Enter
中段Caps Lock ・ ASDFGHJKL ・ ; ・ : ・ 前方削除(Delete)
下段Shift ・ ZXCVBNM ・ , ・ . ・ / ・ ろ ・ Shift
最下段(親指)Ctrl ・ ⌘ ・ ⌥ ・ 英数 ・ Space ・ かな ・ ⌘ ・ ⌥ ・ Ctrl
中段右端のキーは、一般的なMac JISキーボードには存在しない「前方削除(Delete / Macのfn+deleteに相当)」キーです。文字を後ろから消したいときに便利です。

6レイヤー(機能切り替え)

「英数」キーと「かな」キーは、長押しすると別の機能に切り替わる特別なキーも兼ねています。

操作切り替わる内容
「英数」を押しながら他のキー F1〜F12・方向キー・Home/End/PageUp/PageDown・画面の明るさ・音量
「かな」を押しながら他のキー Bluetoothの接続先切り替え(5台まで)・ペアリング情報のクリア

例: 「英数」を押しながら数字の段の7のキー(F7の位置)を押すとF7キーとして動作します。

7トラックボール・エンコーダー

トラックボール(右手側)を転がすと、自動的にマウスカーソル操作に切り替わります(操作をやめるとキー入力モードに自動で戻ります)。

中段のH・J・Kの位置にあるキーは、トラックボール使用中はそれぞれ左クリック・中クリック・右クリックとして使えます。

ロータリーエンコーダー(左手側)を回すと上下にスクロールします。

8ファームウェアについて(上級者向け)

本製品はオープンソースファームウェア「ZMK」で動作しています。キー配列は以下のGitHubリポジトリで公開されており、ご自身でカスタマイズして書き込むこともできます(自己責任でお願いいたします)。

github.com/fuku813-ui/zmk-config-JITRA

GitHub上で自動的にビルドされたファイル(.uf2)を、USBケーブル接続時にリセットボタンを素早く2回押して書き込みモードにしたうえで、表示されるドライブにドラッグ&ドロップすることで書き込めます。

9困ったときは

症状確認してほしいこと
反応しない電池の向き・残量を確認してください
片側だけ反応しないその側の電池を確認し、両方の電源を入れ直してください
Bluetoothが繋がらないPC側で一度ペアリングを解除し、再度ペアリングしてください
特定のキーだけ反応しないスイッチがソケットに正しく挿さっているか確認してください。動作チェックページで、どのキーが反応していないかを確かめられます
