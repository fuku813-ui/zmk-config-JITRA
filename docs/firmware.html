Keymap & firmware guide

キー配列・ファームウェア

JITRA はオープンソースのファームウェア ZMK で動いています。出荷時にファームウェアは書き込み済みなので、そのままお使いいただけます。キー配列を変えたいとき、接続がおかしいときにこのページをご覧ください。

Overview

接続のしくみ

PC とつながるのは右手側(トラックボール側)だけです。左手側(ダイヤル側)は右手側を経由して PC に入力を送ります。

左手側 ⇔ 無線 ⇔ 右手側 ⇔ 無線(Bluetooth)または USB ⇔ PC

  • 右手側を USB で PC につなぐと、有線のキーボードとしても使えます。左右の間は常に無線です。
  • 左手側だけを USB でつないでも、キーボードとしては動きません(書き込み用の接続のみ)。

A — ZMK Studio

ブラウザでキー配列を変える

ZMK Studio を使うと、ファームウェアを書き込み直さずにキー配列を変更できます。変更は JITRA 本体に保存されます。

1

必要なもの

  • Google Chrome または Microsoft Edge(Safari・Firefox は非対応)
  • データ通信対応の USB Type-C ケーブル
2

右手側を USB でつないで接続する

  1. 右手側を USB ケーブルで PC に接続します。ZMK Studio は右手側からのみ接続できます。左手側のキーも右手側からまとめて変更できます。
  2. zmk.studio を開き、USB を押します。
  3. 表示される一覧から JITRA を選んで接続します。
3

キー配置を編集して保存する

  1. 左の一覧でレイヤー(DEFAULT・LOWER・RAISE など)を選びます。
  2. 変更したいキーをクリックし、割り当てるキーや動作を選びます。変更はすぐに反映されるので、試しながら自分用の配置を作れます。
  3. 確定するには、右上の保存アイコン(フロッピーディスクの形)を押します。
保存を忘れずに

保存せずに USB を外したり電源を切ったりすると、変更は消えます。保存前の変更は、右上のゴミ箱アイコンで取り消せます。

MOUSE・SCROLL レイヤーは消さないでください

トラックボールを動かすと MOUSE レイヤーに、スクロール操作では SCROLL レイヤーに自動で切り替わります。レイヤーを削除したり、順番を変えたりすると、トラックボールのクリックやスクロールが正しく動かなくなります。

出荷時の配列に戻したいとき

画面上部の JITRA のメニューから Restore Stock Settings を選びます。C. 書き込みをやり直しても出荷時の配列に戻ります。

B — GitHub

GitHub でファームウェアを作る

ZMK Studio で変更できない設定(マクロ、ダイヤルの動作、トラックボールの速度・向きなど)を変える方法です。GitHub アカウントが必要です。

1

リポジトリを fork する

fork は、JITRA の設定ファイル一式を自分の GitHub アカウントにコピーする操作です。

  1. fuku813-ui/zmk-config-JITRA を開きます。
  2. 右上の Fork → Create a new fork を選びます。
  3. Owner に自分のアカウントを選び、名前はそのままで Create fork を押します。
2

設定を編集する

fork したリポジトリで、次のファイルを編集します。GitHub の画面上で鉛筆アイコンから直接編集できます。

ファイル内容
config/jitra.keymapキー配列、レイヤー、ダイヤルの動作、マクロ
config/boards/shields/jitra/jitra_R.confトラックボールの速度(CONFIG_PMW3610_CPI)、スクロール量、マウス操作中の自動切り替え時間
3

GitHub Actions でビルドしてダウンロードする

変更を保存(Commit)すると、自動でビルドが始まります。2 分ほどで終わります。

  1. fork したリポジトリの Actions タブを開き、左の一覧から .github/workflows/build.yml を選びます。初回は有効化ボタンが出るので押してください。
  2. 一番上(最新)のビルドを開きます。緑のチェックが付いていれば成功です。
  3. ページを下までスクロールし、Artifacts の firmware のダウンロードボタンを押します。

ダウンロードした zip を展開すると、次の 3 つのファイルが入っています。

ファイル用途
settings_reset-seeeduino_xiao_ble-zmk.uf2設定の初期化用(左右共通)
jitra_R-seeeduino_xiao_ble-zmk.uf2右手側用
jitra_L-seeeduino_xiao_ble-zmk.uf2左手側用

C — Flash

ファームウェアを書き込む

左右それぞれに、まず設定の初期化用ファイル、続けて本体用のファイルを書き込みます。左右がつながらない・接続が不安定なときも、この手順で直ります。

出荷時のファームウェアを使う場合

fuku813-ui/zmk-config-JITRA の Actions から、B-3 と同じ手順でダウンロードできます(GitHub へのログインが必要です)。

書き込む前に

設定の初期化を行うと、ZMK Studio で変更したキー配列と、Bluetooth の接続先の登録がすべて消えます。

1

リセットボタンが押せるようにする

リセットボタンはケースの中にあります。本体を裏返してボトムケースを外し、中のコントローラーが見えるようにします。ボトムケースと基板はケーブルでつながったままなので、引っ張らないようにゆっくり開いてください。

2

右手側を書き込みモードにする

  1. 右手側を USB ケーブルで PC に接続します。電源スイッチは OFF のままで構いません。USB ポートは本体の奥側の側面、電源スイッチの隣にあります。
  2. リセットボタンを素早く 2 回押します。
  3. PC に XIAO-SENSE というドライブが表示されれば書き込みモードです。

ドライブが表示されない場合は、USB ケーブルがデータ通信に対応しているか確認してください。

3

設定の初期化用ファイルを書き込む

settings_reset-seeeduino_xiao_ble-zmk.uf2 を XIAO-SENSE ドライブにドラッグ&ドロップします。書き込みが終わると、ドライブは自動で消えます。

Mac をお使いの場合

「デバイスがなくなったため、操作を完了できません。」と表示されますが、書き込みは正常に終わっています。OK を押して次へ進んでください。

4

右手側用のファイルを書き込む

  1. もう一度リセットボタンを素早く 2 回押し、XIAO-SENSE ドライブを表示させます。
  2. jitra_R-seeeduino_xiao_ble-zmk.uf2 をドラッグ&ドロップします。
5

左手側も同じ手順で書き込む

左手側を USB でつなぎ、手順 2〜4 と同じように、settings_reset-…uf2 → jitra_L-seeeduino_xiao_ble-zmk.uf2 の順に書き込みます。

左右のファイルを間違えないでください

右手側に左手用のファイルを書き込むと動作しません。間違えた場合は、正しいファイルを書き込み直せば元に戻ります。

6

電源を入れてリセットボタンを 1 回押す

  1. USB ケーブルを外し、左右を近くに並べて両方の電源を入れます。
  2. 左右それぞれのリセットボタンを 1 回押します。
  3. ボトムケースを閉じます。
7

PC と接続し直す

  1. PC の Bluetooth 設定に古い JITRA が残っていれば削除します。
  2. 一覧に表示される JITRA を選んで接続します。
  3. 動作チェックページで、すべてのキー・ダイヤル・トラックボールが反応するか確認します。

Troubleshooting

困ったとき

ZMK Studio に JITRA が表示されない

Chrome か Edge を使っているか、右手側を接続しているか、USB ケーブルがデータ通信対応かを確認してください。

Keymap Editor で「App Disabled」と表示される

GitHub App の許可に、fork したリポジトリが含まれていません。Add Repository から追加してください。

Actions のビルドが失敗する(赤い ×)

編集したファイルの書き方に誤りがある可能性が高いです。失敗したビルドを開くとエラーの行が表示されます。直前の変更を元に戻すと再びビルドできます。

書き込み後、左手側だけ動かない

左右とも settings_reset から順に書き込み直し、手順 6 で左右を近くに並べた状態で電源を入れてください。

USB でつないでいるのに Bluetooth の機器に入力されない

右手側を USB で PC につなぐと、入力は USB 側に送られます。Bluetooth で使うときは USB ケーブルを外してください。
