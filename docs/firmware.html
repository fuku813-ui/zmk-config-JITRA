Keymap & firmware guide

キー配列・ファームウェア

JITRA はオープンソースのファームウェア ZMK で動いています。キー配列はブラウザから変更できます。目的に合わせて方法を選んでください。

やりたいこと方法GitHub
キーの割り当てを変えたいA. ZMK Studio不要
マクロ・ダイヤルの動作・トラックボール速度なども変えたいB. GitHub でビルド必要
ファームウェアを書き込み直したいC. 書き込みどちらでも
左右がつながらない・接続が不安定D. 接続のリセットどちらでも

A — ZMK Studio

ブラウザでキー配列を変える

ZMK Studio を使うと、ファームウェアを書き込み直さずにキー配列を変更できます。変更は JITRA 本体に保存されます。

1

必要なもの

  • Google Chrome または Microsoft Edge(Safari・Firefox は非対応)
  • データ通信対応の USB Type-C ケーブル
2

右手側を USB で接続する

右手側(トラックボールのある側)を USB ケーブルで PC に接続します。ZMK Studio は右手側からのみ接続できます。左手側の配列も右手側からまとめて変更できます。

3

ZMK Studio を開いて接続する

  1. zmk.studio を開きます。
  2. USB を選び、一覧に出る JITRA を選んで 接続 を押します。
  3. JITRA の配列が表示されれば接続できています。
4

キーを変更して保存する

  1. 画面上部でレイヤー(DEFAULT・LOWER・RAISE など)を選びます。
  2. 変更したいキーをクリックし、下の一覧から割り当てるキーや動作を選びます。
  3. 変更はすぐに反映されます。確定するには右上の Save を押します。
元に戻したいとき

Save 前なら Discard で取り消せます。出荷時の配列に戻すには Restore Stock Settings を押します。

Save を忘れずに

Save を押さずに USB を外したり電源を切ったりすると、変更は消えます。

B — GitHub

GitHub でファームウェアを作る

ZMK Studio で変更できない設定(マクロ、ダイヤルの動作、トラックボールの速度・向きなど)を変える方法です。GitHub アカウントが必要です。

1

リポジトリを fork する

fork は、JITRA の設定ファイル一式を自分の GitHub アカウントにコピーする操作です。

  1. fuku813-ui/zmk-config-JITRA を開きます。
  2. 右上の Fork → Create a new fork を選びます。
  3. Owner に自分のアカウントを選び、名前はそのままで Create fork を押します。
2

設定を編集する

編集するファイルは次のとおりです。GitHub の画面上で鉛筆アイコンから直接編集できます。

ファイル内容
config/jitra.keymapキー配列、レイヤー、ダイヤルの動作、マクロ
config/boards/shields/jitra/jitra_R.confトラックボールの速度(CONFIG_PMW3610_CPI)、スクロール量、マウス操作中の自動切り替え時間

キー配列は Keymap Editor を使うと画面上で編集できます。GitHub でログインし、リポジトリの追加画面では Only select repositories を選んで、fork した zmk-config-JITRA だけを許可してください。

3

GitHub Actions でビルドする

  1. 変更を保存(Commit)すると、自動でビルドが始まります。
  2. fork したリポジトリの Actions タブを開きます。初回は有効化ボタンが出るので押してください。
  3. 一番上のビルドが緑のチェックになったら開き、下部の firmware をダウンロードします。

zip を展開すると、次の 3 つのファイルが入っています。

ファイル用途
jitra_R-seeeduino_xiao_ble-zmk.uf2右手側用
jitra_L-seeeduino_xiao_ble-zmk.uf2左手側用
settings_reset-seeeduino_xiao_ble-zmk.uf2接続のリセット用

C — Flash

ファームウェアを書き込む

右手側・左手側にそれぞれ別のファイルを書き込みます。最新の出荷時ファームウェアはこちらの Actions からもダウンロードできます。

1

書き込みモードにする

  1. リセットボタンはケースの中にあります。本体を裏返してボトムケースを外し、中のコントローラーが見えるようにします。ボトムケースと基板はケーブルでつながったままなので、引っ張らないようにゆっくり開いてください。
  2. 右手側を USB ケーブルで PC に接続します。USB ポートは本体の奥側の側面、電源スイッチの隣にあります。
  3. コントローラーのリセットボタン(写真の赤枠)を、素早く 2 回押します。
  4. PC に XIAO-SENSE というドライブが表示されれば書き込みモードです。
要確認:ドライブ名が XIAO-SENSE で表示されるか実機で確認

ドライブが出ない場合は、USB ケーブルがデータ通信に対応しているか確認してください。

2

ファイルをコピーする

  1. jitra_R-seeeduino_xiao_ble-zmk.uf2 を XIAO-SENSE ドライブにドラッグ&ドロップします。
  2. コピーが終わると自動で再起動し、ドライブが消えます。「ディスクの不正な取り出し」の通知が出ても、書き込みは正常に終わっています。
  3. 左手側も同じ手順で、jitra_L-seeeduino_xiao_ble-zmk.uf2 を書き込みます。
左右を間違えないでください

右手側に左手用のファイルを書き込むと動作しません。間違えた場合は、正しいファイルを書き込み直せば元に戻ります。

D — Reset

接続をリセットする

左右がつながらない、接続が不安定、ペアリングがうまくいかないときの手順です。ZMK Studio で変更した配列も出荷時に戻ります。

1

PC 側の登録を削除する

PC・スマートフォンの Bluetooth 設定から JITRA を削除します。

2

左右両方にリセット用ファイルを書き込む

C の手順で、右手側と左手側の両方に settings_reset-seeeduino_xiao_ble-zmk.uf2 を書き込みます。

3

通常のファイルを書き込み直す

右手側に jitra_R-…、左手側に jitra_L-… を書き込みます。

4

左右を近づけて電源を入れ、接続し直す

左右を並べて両方の電源を入れ、左右がつながるまで 10 秒ほど待ちます。その後、PC の Bluetooth 設定から JITRA を接続します。

Troubleshooting

困ったとき

ZMK Studio に JITRA が表示されない

Chrome か Edge を使っているか、右手側を接続しているか、USB ケーブルがデータ通信対応かを確認してください。

Keymap Editor で「App Disabled」と表示される

GitHub App の許可に、fork したリポジトリが含まれていません。Add Repository から追加してください。

Actions のビルドが失敗する(赤い ×)

編集したファイルの書き方に誤りがある可能性が高いです。失敗したビルドを開くとエラーの行が表示されます。直前の変更を元に戻すと再びビルドできます。

書き込み後、左手側だけ動かない

接続のリセットを行ってください。
